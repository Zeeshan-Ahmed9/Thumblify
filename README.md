# 🧠 Thumblify – AI Thumbnail Generator

Create stunning, high-CTR thumbnails in seconds using AI.  
No design skills required — just describe your idea and download a ready-to-upload thumbnail.

## 🚀 Live Demo
(https://thumblify-pi.vercel.app/)

## ✨ Features

- 🎨 AI Generated YouTube Thumbnails
- ⚡ Real-time Preview
- 🧠 Prompt Based Generation
- 🧩 Style Presets
- 📥 HD Download
- 🔐 Authentication
- ☁️ Cloud Thumbnail Storage
- 📱 Fully Responsive
- 🌙 Dark Mode UI

---

## 🧪 How It Works

1. Enter your video idea/title
2. Choose thumbnail style
3. Generate thumbnails using AI
4. Pick your favorite result
5. Download and upload to YouTube
